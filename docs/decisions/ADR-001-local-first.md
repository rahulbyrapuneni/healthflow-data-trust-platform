# ADR-001: Use a local-first architecture

## Status
Accepted

## Context
The project must remain free, unrestricted, reproducible, and accessible on a personal computer.

## Decision
Use Python, Pandas, DuckDB, Faker, Pytest, and local files for the first release.

## Consequences
- No cloud cost
- No vendor lock-in
- Easy demonstration
- Lower setup complexity
- Distributed-scale features are deferred until justified
